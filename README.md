# Human in the Loop

一个中文生活模拟游戏的首个可玩切片。**雾湾四日**只是工作标题，中文正式名称与宣传语尚未确定。角色、街区和经历均为虚构。

四天、八个行动时段：与小满探索一个小工具，听梅姨讲维修铺的需要，或与乔去海边、赴屋顶晚餐。项目成果、具体约定、生活体验分别影响结局，不设总好感或人生分数。细读与探索约 10–15 分钟；快速点击会更短。

## 在云端运行

需要 Node.js 22.12+（本环境验证版本 24.19.0）。

```sh
cd /workspace/human-in-the-loop
npm ci --cache /tmp/hitl-npm-cache
npm run dev -- --port 5173
```

打开云环境的 **5173 端口预览 / **（直接地址 `http://localhost:5173/`，仅在同一环境或端口转发后可访问）。不依赖个人电脑持续在线。环境自身必须保持运行。本仓库未部署到公网。

```sh
npm test                  # 规则、路径、存档、演示适配器
npm run typecheck
npm run build             # 类型检查 + 生产构建
npx playwright test       # 本环境使用 /usr/bin/chromium
npx playwright test --config playwright.public.config.ts # 生产演示隔离与完整游玩
npm run preview -- --port 4173  # 生产构建演示；无 API 代理
```

浏览器不在 `/usr/bin/chromium` 时设置 `CHROMIUM_PATH`。Playwright 测试包含移动布局、失败请求、取消、重置后迟到响应与重复提交。

## 公开试玩构建

`npm run build` 生成的 `dist/` 是纯静态确定性演示。生产构建禁用实时模型切换，并移除模型 HTTP 请求路径；不托管 `server/`，不需要密钥，不调用付费 API。开发模式保留可选模型接入，规则、剧情与存档行为一致。

## 两种模式

默认**确定性演示模式**不需要联网或密钥：手写剧情、固定规则、少量关键词识别。聊天内容不是实时 AI。自由输入只给出行动提案；确认后由规则执行。未知策略会明确说明切片限制。

可选**实时模型模式**有独立服务端适配器，前端没有模型密钥。最少配置：用户自行选择支持 OpenAI-compatible Chat Completions 与 JSON 输出的供应商和模型，设置三个服务端环境变量，然后启动可选服务：

```sh
cp .env.example .env
# 在云环境编辑 .env，填写 MODEL_BASE_URL、MODEL_API_KEY、MODEL_NAME
node --env-file=.env server/index.mjs
# 另一终端保持 npm run dev 运行，页面点击“切换模型模式”
```

`.env` 已忽略，切勿把密钥放进 `VITE_*` 变量或浏览器。没有供应商或密钥被选定、读取或创建；没有调用付费 API。实时模式测试尚未运行，兼容性与生成质量仍待验证。接入后只有发送对话才请求模型；用户输入与所选角色的共同记忆会发往所选供应商。此服务仅绑定回环地址，用于本云端开发预览，不是可公开部署的认证服务；公网部署前需增加认证、配额与限流。

## 规则与扩展边界

- `src/engine.ts`：唯一权威规则；每次成功行动耗一时段，费用、精力、前置条件、具体记忆、承诺和结局均由规则写入。
- `src/model.ts`：`ModelAdapter` 接口，确定性演示与 HTTP 实时路径分离。输入是尝试，不是成功断言。
- `server/index.mjs`：只提供所选角色设定和自己的记忆；输出只接受文字和已知行动 ID，不接收资源变更。前端始终显示提案并重新验证条件。
- 新策略可由模型映射为现有行动；完全新行为需要扩展规则。目前没有任意行动的通用裁决器。模型文本仍可能产生幻觉，但不会变成权威状态或永久记忆。
- `src/main.ts`、`src/style.css`：响应式界面、角色对话、记事本、结局与存档。
- 存档为浏览器 `localStorage`，每步自动保存，可手动保存/读取。读取时重放行动并比对全部状态；损坏、不同版本或不一致的存档会被拒绝。单存档槽，重开需二次点击确认。没有跨设备同步；未来修改剧情需要迁移存档版本。
- 同一提交中的重复对话请求被拦截；切换模式、读取、重开、取消会使旧回复失效。每个独立场景不可重复刷奖励；零工与休息可重复，但都耗时段。
- 下周回访是被记录的未来约定，超出本切片范围。关系修复、更多自由行动和持续人生模拟尚未实现。

## 验证范围

确定性测试覆盖资源/时间边界、非法行动不变更状态、失败试用后修正、角色记忆隔离、承诺兑现/失约、不同结局、存档重放校验和重置。浏览器验证不使用真实模型，网络响应被模拟。公开发布的实际状态以 GitHub 分支与 Sites 部署记录为准。
